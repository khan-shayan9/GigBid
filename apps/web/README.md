GigBid web app: Next.js (App Router), TypeScript strict, Tailwind. Screens: sign-in and
onboarding, inbox, job detail, proposal studio, pipeline, messages, run viewer, analytics and
settings (with the memory viewer). It talks only to the API through the client typed from
`src/lib/api/schema.d.ts` (generated by `make api-client`; never edit it). See `docs/RUNBOOK.md`
("Web app") for running it and `make e2e` for the Playwright tests.
